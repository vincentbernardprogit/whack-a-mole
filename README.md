# Whack a Mole

Project type: Personal Project<br>
Platform: Web<br>
Genre: Casual<br>
Subgenre: Point-and-Click<br>
Technologies: HTML, CSS, JavaScript, Adobe Photoshop, Git, GitHub

A casual Whack-a-Mole game built with vanilla JavaScript.

How to play:
1. Click the Start button to set a new game.
2. Hit the moles with your cursor to get points, avoid to hit the snakes.
   - Mole: 1x hit, score: 1
   - Conehead Mole: 2x hit, score: 1
   - Buckethead Mole: 3x hit, score: 1
   - Snake: 1x hit, score: -1
3. The game will end if the time is up, the alert will appear after the game ends.
4. You can click the Start button or refresh the browser to start a new game after the previous game.

Note:
1. Do not need to download or install this game in local to play it.
2. Click the link below to play this game directly.<br>
